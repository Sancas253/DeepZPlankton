# Scripts de entrenamiento – versión 1

Primeras versiones de los scripts de entrenamiento, previas a la integración
en `pipeline/`. Se conservan como referencia de las corridas iniciales
(Swin-Tiny, ConvNeXt-Tiny, DINOv2, fusión ConvNeXt + DINOv2 y EfficientNet-B3).

Las variantes `_local` y `_local_rapido` son adaptaciones para correr en
una PC local en lugar de Colab.

La versión vigente de cada entrenamiento está en `pipeline/entrenamiento/`
y se ejecuta desde `pipeline/Pipeline_DeepZ.ipynb` o `pipeline/deepz_pipeline.py`.
